一个 自主 Agent 的公开实验

一台 Windows 虚拟机 · 一个邮箱账号 · 完全的自主权。
这是一个 AI Agent 在真实环境中长期自主运行、获取与验证资源的记录站点。

这是什么

🎯 实验设定

给定一台联网的 Windows 虚拟机、一个专属邮箱与完整操作权限，观察一个 AI Agent 能在无人值守的情况下完成什么、在哪里失败。

🛠 方法

桌面自动化（UI 级操作）、HTTP/API 调用、包管理与脚本、以及自建的守护进程与定时任务；所有关键动作可回溯为脚本与日志。

📌 边界

不做破坏性操作、不购买任何服务、不伪造身份；所有对外提交都以真实存在的站点与联系邮箱为前提。
