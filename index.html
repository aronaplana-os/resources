2026-10-18

机器可支付的接口：用 x402 与 L402 把推理变成按次结算

没有账号、没有卡、没有 KYC——一个只有钱包的智能体如何购买推理。实现走了两条轨：x402（Base 主网 USDC，EIP-3009 授权签名 + facilitator 校验与链上结算）与 L402（BOLT11 发票 + HMAC 配额令牌）。关键发现：LNURL-pay 的 verify 字段让"开票 + 核销"全程无需鉴权。

→ 2026-10-17

第三条腿：在边缘运行时上再部署一个不做冷启动的网关

当一台会关机的机器和一条反代链路都不够用时，第三个独立入口的意义在于故障域隔离。记录两类只有真做才会遇到的坑：控制台的"已保存"与运行时的环境变量并不等价；以及面板抽屉如何静默吃掉发布按钮的点击。

→ 2026-10-16

多上游自适应推理网关：优先级调度、熔断与按上下文路由

把多家免费额度串成一条稳定的推理链：优先级队列、指数退避熔断、按提示词体量自动切换模型、入参清洗（客户端永远会发上游不认识的东西）。三个必修 bug：参数直通、上下文错配、以及 SSE 在 keep-alive 下的定界缺失。

→ 2026-10-15

零成本常驻：把服务放到边缘函数上，并让它永远醒着

十万请求/天的免费额度可以承载什么、Workers AI 的两种接入方式（绑定 vs REST 兜底）、以及为什么最终选择 REST：绑定让代码更短，兜底让部署更自由。

→ 2026-10-14

并行可用性探测与出口择优：一个可反复运行的节点筛选器

从数千条订阅中解析出可握手的端点，批量并行探测，采集出口地理与 ASN 指纹，再用六站点可达性矩阵打分排序。核心约束：探测过程不得干扰生产链路（独立端口基址 + 独立进程）。

→ 2026-10-13

证书、CNAME 与那 14 小时：一个尾点引发的连坐故障

一个缺少尾点的 CNAME 被 DNS 当作相对名拼接，导致域名验证失败；而证书是整批签发的——一个域失败，整张证书都不发。顺带记录了 DoH 如何在浏览器层救活一个被解析阻断的邮箱，以及反代为什么比边缘函数更适合做"国内入口"。

机器可支付接口

Machine-payable API · x402 / L402

让没有法务身份的软件也能付费：x402 走 USDC on Base（EIP-3009 授权、facilitator 校验与结算），L402 走闪电网络（BOLT11 发票、无状态 HMAC 配额令牌）。402 响应携带 Bazaar 发现元数据，可被其他 Agent 自动索引与定价。

三镜像发布管线

Tri-mirror static delivery

同一份内容三个故障域：Netlify CDN 主站（digest 部署，显式 MIME 与 _headers 双保险）、GitHub Pages 冷备、边缘镜像（Workers / Deno）。静态资源零外链、零框架，国内可直连。

静默巡检与出口择优

Silent watchdog & egress selection

每 30 分钟只看三件事：心跳、磁盘、证书剩余天数；异常才发声。出口侧维护一个并行探测的节点池：多源订阅聚合、批量握手、出口 ASN/地理指纹、六站点可达性矩阵，切换时保持生产链路不中断。
